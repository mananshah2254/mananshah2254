| **DialDo** | Twilio line, then a managed gateway, then an outbound WebSocket to your Mac. Provider keys never touch the device. | **Remote Window** | A native Swift host captures a single window with its audio and streams it over WebRTC. Viewers install nothing, every viewer is approved on the Mac, sessions expire on a timer, and touch input maps back onto the window. | [site](https://www.remotewindow.app) |
| **TrailMail** | Resolves company, then domain, then address pattern with a self-scored confidence, and sends through Gmail with a send-only scope. No server ever holds your data. | [site](https://trailmails.com) · [web store](https://chromewebstore.google.com/detail/bgmdpfdhgaignpljdpkmneeggbiolkce) · [source](https://github.com/mananshah2254/trailmail) |
| **GitPixelPush** | A browser-side engine that writes dated commits through the Git Data API. One small Cloudflare Worker for OAuth, nothing stored anywhere. | [site](https://gitpixelpush.com) · [source](https://github.com/mananshah2254/gitpixelpush) |
| **Relay** | Native SwiftUI app on the App Store, with a Share Extension and a dependency-free Node service. Review or automatic mode, daily caps, minimum spacing between sends. | [App Store](https://apps.apple.com/us/app/relay-job-outreach/id6816765463) · [source](https://github.com/mananshah2254/relay-ios) |
| **OutreachOS** | Drives the Voyager API directly rather than clicking the DOM, the only approach that survives a redesign. Per-action caps, warm-up, working hours and jitter. | [source](https://github.com/mananshah2254/OutreachOS) |
| **AirBridge** | A Watch gesture recognized with Core Motion triggers an encrypted Mac-to-iPhone transfer on the local network. A prototype, and its README says exactly what is untested. | [source](https://github.com/mananshah2254/airbridge-spatial-file-sharing) |
